# 두 사용자로 찍 시연

1. README대로 API·worker·프론트를 실행하고 seed를 적용합니다. http://127.0.0.1:5173 에서 **샘플 앨범 둘러보기**를 누르면 지수로 로그인합니다. 실제 데이터가 저장된 제주 여행 12장과 다른 샘플 앨범을 볼 수 있습니다.
2. 별도 브라우저 프로필/시크릿 창에서 `minji@moacut.local` / `MoacutDemo123!`로 로그인합니다. 같은 브라우저의 일반 탭끼리는 쿠키를 공유하므로 계정을 분리하려면 독립된 프로필을 사용하세요.
3. 지수가 전체 앨범 → 새 앨범 만들기로 시연용 앨범을 만듭니다. 초대하기에서 코드를 복사해 민지가 **초대코드로 참여하기**에 입력합니다.
4. 인물 관리에서 `frontend/public/demo/avatar-jisu.jpg`, `avatar-minji.jpg`를 각각 등록합니다. 계정 연결을 제안한 뒤 **당사자 계정에서 연결 확인**을 눌러야 합니다. 이름만 같아도 계정과 자동 연결되지는 않습니다.
5. 지수가 `frontend/public/demo/photo-02.jpg`를 업로드합니다. 민지도 `photo-01.jpg`를 올려 봅니다. 파일 저장 직후 분석 대기 → 분석 중 → 완료가 바뀝니다. 해당 fixture는 각각 지수+민지, 지수로 연결됩니다. 모든 고정 결과는 샘플입니다.
6. 여러 파일과 지원하지 않는 파일을 같이 선택해 파일별 성공·실패를 확인합니다. 실패한 파일만 재시도할 수 있습니다. 같은 업로드 요청의 재시도는 중복되지 않습니다. 의도적으로 파일을 새로 선택하면 별도 사진으로 저장됩니다.
7. 내 사진·인물 버튼·혼자/함께·태그로 필터링합니다. 상세 검색에서 여러 인물과 ‘모두 포함/누구든’을 조합합니다. `지수가 나온 바다 사진`처럼 이름+태그로 검색할 수 있습니다.
8. 지수+민지 사진의 보정하기를 엽니다. 밝기와 채도를 조절하고 이름을 붙여 **새 보정본 저장**을 누릅니다. 보정 기록에서 원본/이전 버전을 선택하고 슬라이더로 비교합니다. 저장은 항상 원본 기준 전체 설정입니다.
9. 함께 고르기 탭에서 등장 멤버와 승인 대상을 확인하고 체크 후 **확인 요청 보내기**를 누릅니다. 지수가 승인해도 민지 승인 전에는 합의가 끝나지 않습니다. 민지가 같은 버전을 선택해 승인하면 합의 완료가 됩니다.
10. 합의 완료 버전을 **최종본**으로 지정합니다. 다운로드 메뉴에서 원본, 선택 보정본, 최종본이 구분되는지 확인합니다. 원본은 업로드한 바이트와 동일하고 보정본은 해당 버전의 원본 해상도 결과입니다.
11. 다른 보정본을 새로 만들면 승인은 0개부터 시작하고 기존 최종본은 유지됩니다. 최종본에서 승인을 취소하면 최종본 지정이 해제됩니다. 인물 연결 변경 시 기존 승인 요청은 재검토가 필요합니다.
12. 사진 상세에서 버전 댓글/수정 요청과 사진 메모/용도를 저장하고 새로고침합니다. 함께 고르기 보드와 알림에 저장된 상태가 반영됩니다.
13. 모바일 화면에서 하단 전체 앨범·내 사진·함께 고르기로 이동하고, 큰 사진 아래 패널에서 보정/승인을 수행합니다.
14. 앨범 상단의 톱니바퀴 **앨범 설정**을 엽니다. 지수는 이름·소개·여행 시간대를 저장하고 새 초대코드를 만들 수 있습니다. 민지에게는 읽기 전용 정보와 **이 앨범 나가기**가 표시됩니다. 새 초대코드는 이미 참여한 멤버를 내보내지 않습니다.
15. **사진 정리 현황**을 열어 전체 사진의 완료/분석 중/대기/확인 필요 장수와 실제 저장된 분석 기록을 확인합니다. 실패한 항목을 누르면 해당 사진 상세가 열립니다. **실패한 사진 재분석**은 실패 작업만 다시 요청합니다. fixture에 없는 일반 사진은 재요청해도 자동 분석되지 않습니다.
16. 시연용 사진 상세의 **사진 정보**에서 분석 기록을 펼칩니다. **사진 삭제**는 업로더 또는 앨범 소유자만 사용할 수 있고, 모든 멤버에게서 원본·보정본·승인·댓글이 삭제된다는 체크를 해야 실행됩니다. 삭제 후 선택 바에 남지 않는지 확인합니다.
17. 시연용 앨범에서 멤버 내보내기·탈퇴를 확인합니다. 사진은 남지만 해당 인물의 계정 연결은 해제되고 관련 승인/최종본은 재검토가 필요합니다. 마지막으로 소유자가 앨범 설정에서 앨범 이름을 정확히 입력해 시연용 앨범을 삭제합니다. 기본 샘플 앨범 대신 별도 시연용 앨범에서 진행하세요.

## 샘플 분석 경계

- `sample-no-face.jpg`: 얼굴 없음 → 업로더가 기본 승인 대상.
- `sample-unknown-face.jpg`: 미등록 얼굴 → 승인 대상을 직접 확인해야 하며 자동 승인되지 않음.
- `photo-03.jpg`: 4명 fixture. 4개 인물의 계정이 연결되어야 모두 확인할 수 있음.
- 임의의 새 이미지: 파일 저장은 성공하나 fixture 분석 실패. 보정·다운로드는 계속 가능. 실제 자동 분석에는 Rekognition 연결 필요.
- HEIC: 지원하지 않음. JPEG/PNG로 변환 후 업로드.

실제 사진의 AI 정확도 시연으로 소개하지 마세요. 원본 참고 이미지에서 잘라낸 낮은 해상도의 일러스트 샘플이며 촬영일·GPS는 없습니다.
