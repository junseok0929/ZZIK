# 참고 이미지와 데모 자산

사용자가 제공한 다음 두 디자인 이미지를 화면 구성의 기준으로 사용했다. 원본 파일은 수정하지 않았다.

- `KakaoTalk_Photo_2026-09-16-21-31-20 001.png`
- `KakaoTalk_Photo_2026-09-16-21-31-21 003.png`

`scripts/prepare_demo_assets.py`는 이 이미지의 사진·아바타 영역을 잘라 `frontend/public/demo/`에 JPEG 데모 자산을 만든다. 12개 사진, 4개 아바타, 얼굴 없음·미확정 얼굴의 동작 확인용 샘플 2개로 구성한다. 일부 영역에는 원래 디자인의 합성·문구·화면 요소가 포함될 수 있다. 실제 사용자가 업로드한 원본 사진이나 실제 인물 식별 결과로 취급하지 않는다.

`backend/fixtures/manifest.json`은 각 파일의 SHA-256에 연결된 지정 결과다. 이름·얼굴 위치·유사도·태그는 화면과 API 흐름을 확인하기 위한 예시이며 사진 내용의 정답 주석이나 모델 정확도 증거가 아니다. 참고 화면에서 잘라낸 아바타 역시 얼굴 인식 검증용 기준 사진으로 적합하다고 확인하지 않았다.

재생성은 저장소 루트에서 다음 명령으로 한다. 이미지 인코딩 환경이 바뀌면 해시도 바뀔 수 있으므로 생성된 JPEG와 manifest를 함께 갱신한다.

```sh
.venv/bin/python scripts/prepare_demo_assets.py
```

데모 자산은 프론트의 `/demo/` 경로에서 공개 정적 파일로 제공된다. 실제 업로드 사진은 이 경로에 복사하지 않고 인증이 필요한 API와 비공개 저장소로 제공한다.

외부 재배포·상업적 사용에 대한 이미지 라이선스는 확인되지 않았다. 현재 자산은 사용자가 제공한 디자인 참고 자료이며, 사용자 요청에 따른 개발·팀원 공유용 예시로 포함한다. 별도 재사용 라이선스를 부여하지 않는다. 제3자의 재배포나 상업 서비스에 사용하는 경우 권리 확인 또는 허가된 자산으로 교체해야 한다. 외부 스톡 사진을 새로 다운로드하거나 사용 권리를 임의로 주장하지 않았다.
